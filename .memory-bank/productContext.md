# Product Context

This is a personal blog that renders a list of articles and individual article pages fetched via API. Users expect:

- Fast initial load and smooth route transitions.
- Clean typography and readable content on mobile and desktop.
- Stable deep links such as /article/:id.
- Accessible navigation with keyboard support and proper document titles.

We must preserve current branding: title "TL's Blog" and GitHub link.
