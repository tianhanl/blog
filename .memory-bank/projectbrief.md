# Project Brief

Modernize a small blog app currently using a custom Webpack setup and React 18 UI. Goals:

- Upgrade build pipeline for DX and performance (HTML injection, code splitting, cache-busting).
- Keep Cypress e2e working; preserve app structure and routes.
- Maintain existing API behavior and React components.
- Prepare groundwork for further UX polish without large rewrites.

Non-goals: Migrating to a new framework or SSR; changing API contracts.
